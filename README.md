# Fabry-Pérot Etalon Simulation
Simulation of a Fabry-Pérot optical cavity using Python (NumPy, SciPy, matplotlib).

## What this project covers
- Transmission spectrum as a function of mirror reflectivity
- Effect of cavity length on Free Spectral Range (FSR)
- Finesse comparison: analytical formula vs. numerical measurement from simulation

- fabry_perot.py — full simulation code
- Fabry_Perot_Etalon.pdf — full project report
